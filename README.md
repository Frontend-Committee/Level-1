# Portfolio

## Project Objective
The objective of this project is to style a multi-section portfolio website using CSS only.  
The project focuses on applying the CSS topics covered this week to improve layout, spacing, colors, and overall visual structure without using any JavaScript.

## CSS topics used
- CSS Selectors
- Box Model
- Positioning
- Display Property
- Lists Styling
- Links Styling
- Forms Styling

## GitHub Workflow Steps
1. Clone the repository to the local machine.
2. Make changes to the project files.
3. Stage changes using Git.
4. Commit changes with a meaningful message.
5. Push commits to the remote repository on GitHub.
